# 딸깍 (ttalkkak)

> ⚠️ **아직 개발 중입니다.** 기능이 바뀌거나 동작하지 않을 수 있어요.

PC방에서 자리를 비운 사이에도 **폰으로 리그 오브 레전드 매칭을 시작·수락하고 챔피언을 고르는** 프로그램입니다.
PC 에서 `딸깍.exe` 를 켜 두고, 폰으로 QR 을 찍거나 PIN 6자리를 넣으면 연결됩니다.

## 할 수 있는 것

- 게임 모드 고르기 (소환사의 협곡 · 칼바람 · 특별 모드 · TFT — 롤 클라이언트에 보이는 큐 그대로)
- 포지션 1·2지망, 신속 대전 미리 고르기 (챔피언 · 포지션 · 소환사 주문 · 룬)
- 매칭 시작 · 취소 · 수락 · 거절
- 챔피언 선택: 금지 · 선택 · 확정, 칼바람 카드 · 벤치 교환, 교환 요청 수락/거절
- 룬 페이지 고르기 · 고치기

시간 · 단계 · 고를 수 있는 챔피언은 전부 롤 클라이언트가 보낸 값을 그대로 씁니다.

## 쓰는 법

1. PC 에서 롤 클라이언트를 켜고 로그인합니다.
2. `딸깍.exe` 를 실행하고 비밀번호를 넣습니다.
3. 창에 뜬 QR 을 폰 카메라로 찍거나, 폰에서 주소를 열고 PIN 6자리를 넣습니다.

폰이 데이터, PC 가 PC방 유선이어도 중계 서버(Cloudflare Workers)를 거쳐 연결됩니다.

## 만들기 (개발)

```bash
npm install
npm test                 # 가짜 롤(mock-lcu)로 자체 시험
npm run mock             # 가짜 롤 클라이언트
npm run agent:mock       # 가짜 롤에 붙는 에이전트
npm run build            # dist/딸깍.exe (Node SEA, Windows)
```

- `agent/` — PC 에이전트. 롤 클라이언트 로컬 API(LCU)에 붙고, 폰 명령은 `agent/lcu.js` 의 허용 목록만 통과시킵니다.
- `web/` — 폰 화면
- `relay/` — 중계 서버 (Cloudflare Worker + Durable Object, PIN 마다 방 하나)
- `mock-lcu/` — 시험용 가짜 롤 클라이언트
- `test/selfcheck.js` — 자체 시험
